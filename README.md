# zero-beat · 零拍

**B 站音乐终端播放器。** 在终端里搜索、收藏、排队、播放 B 站音频，带逐行歌词。

> 名字取自无线电里的 *zero beat*：两个振荡器频率完全相同时差拍归零，听不出接缝。

> **状态：v0.1 可用。** B 站单源已打通：扫码登录、搜索、收藏夹、播放、队列、歌词、音量补偿、断点恢复。
> 网易云与更多能力见 [ROADMAP.md](ROADMAP.md)。

---

## 现在能做什么

| 能力 | 说明 |
| --- | --- |
| 扫码登录 | 终端内渲染二维码，cookie 保存在本地，重启自动恢复 |
| 搜索 | B 站视频搜索（WBI 签名，签名失效自动回退），`enter` 直接播放 |
| 收藏夹 | 登录后自动读取收藏夹，首次进入拉取并缓存到本地 SQLite |
| 播放 | 自动选最高码率 AAC-LC（192k），避开 64k 的 HE-AAC 轨道 |
| 队列 | 顺序 / 单曲 / 随机，重启后恢复队列与进度 |
| 歌词 | 取视频字幕，按播放位置逐行高亮 |
| 音量 | 用户音量 + dB 音量补偿（软限幅防削波），切歌即时生效 |
| 歌单 | 本地歌单，`a` 一键加入，`d` 移除 |

## 安装

依赖：

- **Go 1.26+**（`charm.land/*` 与 `oto/v3` 要求）
- **ffmpeg**（负责解码 AAC / HE-AAC / FLAC）
- 可用的音频输出：Linux 上 PulseAudio/PipeWire，macOS CoreAudio，Windows WASAPI

```bash
git clone https://github.com/Sheyiyuan/zero-beat && cd zero-beat
make build          # 产出 bin/zero
./bin/zero          # 进终端界面
```

## 用法

```bash
zero                     # 终端界面
zero login               # 只扫码登录，保存 cookie
zero play BV1GJ411x7h7   # headless 播放，用来验证音频链路
zero demo [view]         # 打印一帧示例界面（library/search/queue/lyrics/help/login）
```

## 按键

| 键 | 作用 |
| --- | --- |
| `enter` | 播放选中项 |
| `space` | 暂停 / 继续 |
| `n` / `p` | 下一首 / 上一首 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `+` / `-` | 音量 ±5% |
| `[` / `]` | 音量补偿 ∓1 dB |
| `m` | 播放模式（顺序 / 单曲 / 随机） |
| `j` / `k` | 上下移动 |
| `h` / `l` | 切换歌单（曲库视图） |
| `a` / `A` | 加入歌单 / 加入播放队列 |
| `d` | 从歌单或队列移除 |
| `/` | 搜索 |
| `L` | 扫码登录 |
| `tab` | 切换视图（曲库 → 搜索 → 队列 → 歌词 → 帮助） |
| `1`–`6` | 直接跳视图 |
| `?` | 帮助 |
| `r` | 刷新当前列表（收藏夹会重新拉取） |
| `q` / `ctrl+c` | 退出 |

## 数据与隐私

- 全部本地存储：`~/.config/zero-beat/zero-beat.db`（SQLite，纯 Go 驱动，无需 cgo）。
- 登录 cookie（`SESSDATA` 等）原样存在本地数据库里，**当前未加密**，请自行保护数据目录权限；OS keyring 在路线图里。
- 播放直链不入库，每次播放时现解析（B 站地址约 2 小时过期）。
- 应用只访问 B 站官方接口与 CDN，不上报任何数据。

## 已知限制

- **只有 B 站**。网易云是下一步（见 ROADMAP）。
- **歌词只来自视频字幕**，没有字幕的视频显示"暂无歌词"；LRCLIB 等外部歌词源在路线图里。
- **没有封面图**。终端图形协议（kitty/sixel）还没做。
- **seek 会重开 ffmpeg 进程**，大约 0.3–1 秒的停顿，不是瞬时跳转。
- **收藏夹全量拉取**（上限 300 首），超大收藏夹会慢一点。
- **没有系统媒体控制**（MPRIS/媒体键）与桌面通知。
- 登录页二维码需要终端高度 ≥ 32 行；更矮时会退化成链接提示。

## 架构

```
cmd/zero             CLI：tui / play / login / demo
internal/tui         Bubble Tea v2 界面：模型、渲染、按键、命令
internal/bili        B 站客户端：WBI 签名、播放地址、收藏夹、字幕、扫码
internal/audio       播放引擎：ffmpeg 解码 → 增益链 → oto 输出，事件通道
internal/lyrics      LRC 解析与时间轴定位
internal/store       SQLite：歌曲、歌单、队列、设置、登录态
internal/config      数据目录
```

关键契约只有一个：`audio.Stream{URL, Headers, Codec, DurationMS, ExpiresAt, Quality}`。
音源负责把平台差异（Referer、cookie、编码）压进这个结构，引擎只认它。

详见 [ARCHITECTURE.md](ARCHITECTURE.md)。
