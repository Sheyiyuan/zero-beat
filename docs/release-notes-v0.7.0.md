## 新功能

### 登录态续期

- 启动时与运行中每 12 小时主动向平台续期一次登录态，续期成功后立即写回本地；距上次续期不足 6 小时会跳过，避免频繁换发把同账号的其它客户端顶掉。
- 后台账号校验遇到「已过期」时先尝试续期一次：续期成功就保持登录，只有平台明确拒绝才判定过期并冻结歌单。
- 登录态只在内容真的变化时落盘，避免反复刷新更新时间、误解冻歌单或误触发同步。
- 网易云按 PC 客户端身份（`os` / `appver` cookie）发请求，减少登录态被判定「身份不一致」而提前失效。

### 本地音乐库

- 手动添加一个文件夹，它就是一个**只读歌单**：`N` →「添加本地文件夹」，或 `zero library add <路径>`。
- 只扫描当前层，不递归、不监听；发现子文件夹时提示「未扫描 N 个子文件夹」，`lyrics/` 不计入。
- 打开歌单时距上次扫描超过 60 秒会自动重扫，`r` 立即重扫。目录暂时不可用（移动硬盘没挂载、U 盘拔了）时保留上次内容，只标记为「不可用」。
- 文件夹歌单只读：不能手动加歌、删歌、排序；可以 `R` 改名、`N` →「更换当前文件夹」换目录、`D` 移除（只删索引，不删音频、歌曲行与注释）。
- 侧栏标记：`[夹]` 文件夹歌单、`[仅]` 仅本机歌单。
- 曲目身份来自音频标签（标题 / 艺术家 / 专辑 / 碟号 / 轨号）与内容指纹，不是路径：改名、移动文件或改标签都不会换歌，注释与歌词绑定不会丢。
- 下载目录可以直接加成本地文件夹歌单：命中下载记录的文件继续显示为原来的平台曲目，不会多出一份本地副本；删掉下载记录后，下次扫描它会退回本地曲目。
- 本地曲目可以直接播放、seek、预解析与进队列，和平台曲目混排。时长优先用标签/容器头，缺失时首次播放用一次 `ffprobe` 补上。

### 本地歌词

对本地曲目按顺序找歌词，任一级拿到带时间轴的就停：

1. 音频同目录、同名 stem 的 `.lrc`（也认 `song.flac.lrc`）；
2. 同目录 `lyrics/` 子目录里的同名 `.lrc`；
3. 归一化文件名匹配：`艺术家 - 歌名`、`歌名 - 艺术家`、`歌名`（忽略开头音轨号、空白与标点）；
4. `.lrc` 里的 `[ti:]` / `[ar:]` 与歌曲标签匹配；
5. 内嵌歌词（ID3v2 USLT、FLAC/Ogg `LYRICS`、MP4 `©lyr`）；
6. LRCLIB 兜底。

- 编码支持 UTF-8（含 BOM）、UTF-16（含 BOM），失败按 GB18030 解码；单文件上限 2 MiB。
- 支持一行多时间戳、`[offset:±N]`、增强 LRC 的 `<mm:ss.xx>`（词级标签会被剥掉）。
- 纯文本、没有时间轴的歌词不会被使用。
- 翻译：同时间戳的双语行合并为原文 + 译文；`<stem>.trans.lrc` / `<stem>.zh.lrc` 作为独立翻译文件按时间戳合并，冲突时以独立文件为准。
- `~/.config/zero-beat/lyrics.toml` 可调候选顺序、翻译方式与文件大小上限，只在本机生效：

```toml
[local]
candidate_order = ["stem", "artist-title", "title-artist", "title", "tag"]
translation = "both"   # both | same-timestamp | sidecar
max_size_kb = 2048
```

### 歌词来源绑定

- 新增快捷键 `B`（`bind_lyrics`，任意页面可用），打开「歌词来源」浮层，作用于正在播放的歌。
- 默认按清洗后的歌名搜索；`/` 编辑搜索词（`←` / `→` 移动光标、`backspace` / `delete` 删字符、`ctrl+u` 清空），`enter` 重新搜索，`esc` 只退出编辑。
- `Tab` 在 全部 / 网易云 / LRCLIB 之间切换；`↑` / `↓` 选候选；`enter` 先取一次歌词并预览（前 3 行 + 总行数），再确认落库。没有时间轴的歌词会被拒绝，不会落库。
- `l` 从本机曲目里挑一首（用它的旁挂/内嵌歌词），`u` 输入本地路径、`netease:<歌曲ID>`、`lrclib:<记录ID>` 或网易云链接；`x` 解除绑定，`esc` 取消。
- 绑定只存引用，不存歌词正文：平台歌曲 / LRCLIB 绑定存 `lyric_bind:<songID>` 并随注释同步；本地文件 / 本机曲目绑定存 `lyric_bind_local:<songID>`，不同步。
- 绑定优先于自动来源；绑定失效（源未登录、记录被删、文件丢失）会降级到自动来源并在歌词页提示「绑定失效，已回退」，不会自动清除绑定。
- 偏移属于当前歌词来源：`<` / `>` / `0` 调整的是「这一版歌词」的偏移，换源就换偏移。新绑定从 0 开始；本地文件被移动时重新选一次路径即可保留偏移。
- 绑定到歌曲自己等于解除绑定。

### 同步格式 v2

- 同步仓库 `meta.v` 升到 2，新增 `playlists.sync_excluded` 与注释里的 `lyric_bind` 字段。
- 文件夹歌单、引用文件夹的混合歌单、显式创建的「仅本机歌单」都不导出；导入（包括 `KeepLocal=false`）也不会删除它们。导出与导入删除共用同一份可同步集合。
- 本地曲目上的注释与本地歌词绑定不进仓库。
- 同步页显示「仅本机 N 个歌单 · 本机注释 M 条」。
- v1 仓库仍可读取：首次成功同步后**原地升级**为 v2，并在同步结果里提示。升级不可回退；旧客户端读到 v2 会要求升级，而不是带着不认识的字段继续导出。

## 行为变化

- 登录页、账号摘要与 CLI 登录入口只遍历有账号能力的音源；本地库不会显示成需要扫码的音源。
- `w` / `W` 对本地曲目直接提示「不需要下载」，下载页也不会出现 `source=local` 的记录。
- 删除下载记录但保留文件时，下次扫描该文件会变成本地曲目（预期行为）。
- 移除文件夹歌单只删索引，保留歌曲行与注释；重新添加同一目录会复用身份。
- 扫描文件夹不会触发同步：文件夹歌单与本地曲目都属于仅本机数据。
- 新增 CLI：`zero library add|list|scan|remove`、`zero lyrics show|bind|unbind`。
- 新增 `zero demo lyricbind` 预览歌词来源浮层。

## 升级注意

- **多设备必须先升级所有设备，再让任意一台执行同步。** v2 仓库会切断旧客户端；旧客户端参与同一仓库可能把仅本机歌单重新导出，或在导入时删掉它们。
- 同步格式升级只改 `meta.json` 版本号，不重新派生密钥，其它设备不需要重新输入口令。
- 数据库自动迁移：`playlists` 新增 `sync_excluded` / `root_path` / `scan_status` / `scan_error` / `scanned_at` 列，新增 `library_files` 表与 `downloads(path)` 索引；旧库打开时自动补齐，不需要手工操作。
- `lyrics.toml` 是可选的本地配置；不存在时使用默认值，不参与同步。
- 新增依赖 `github.com/dhowden/tag`（BSD-3-Clause）读取音频标签，已写入 `THIRD_PARTY_NOTICES.md`。
- 本地音乐库需要手动添加目录，不会自动扫描已知目录；本地封面与 MPRIS 完整元数据不在本版。

## 升级前验证

```bash
make check
go test -race ./...
```

手工检查：

1. `zero library add ~/Music`：确认生成只读歌单、有子目录时提示未扫描；改名/移动文件后重扫不换曲目。
2. 下载目录作为文件夹歌单：确认平台曲目没有变成重复的本地曲目；删除下载记录后重扫变回本地曲目。
3. 本地 `.lrc`：同名、`lyrics/`、`艺术家 - 歌名`、GB18030、`[offset:]`、`.trans.lrc` 各准备一个，确认来源与偏移正确。
4. 按 `B` 绑定网易云或 LRCLIB，确认预览后落库；删掉本地文件后确认降级提示且绑定仍在。
5. `<` / `>` 调偏移后换一个绑定：确认偏移跟着来源，不串到别的绑定。
6. 两台设备：确认文件夹歌单、仅本机歌单、本地注释与本地绑定不出现；`KeepLocal=false` 拉取后本机数据仍在。
7. v1 仓库首次同步：确认 `meta.json` 升到 2 且同步页有升级提示。
