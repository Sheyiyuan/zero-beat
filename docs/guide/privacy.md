# 数据与隐私

## 本地存储

所有数据都存在本地 `~/.config/zero-beat/zero-beat.db`（SQLite）。

- 登录 cookie（B 站 `SESSDATA`、网易云 `MUSIC_U`）保存在本地数据库里，请自行保护数据目录权限。
- 播放地址不会保存，每次播放临时获取，一段时间后自动失效。
- 本地音乐库只索引你手动添加的目录：路径、文件大小/时间与内容指纹写进数据库，音频文件本身不动、不上传。`lyrics.toml` 与歌词文件都在本机，不同步。
- 歌词来源绑定只保存引用（平台 ID / LRCLIB ID / 本地路径），不保存歌词正文。

## 控制通道

运行中的 TUI 会在数据目录下开一个 0600 的 `control.sock`，只接受本机同一用户的 `zero frame` / `zero +<按键>` / `zero +type`，用于读取界面和注入按键。它不联网，也不上报数据。

## 网络访问

应用访问 B 站官方接口 / CDN、网易云网页端接口 / CDN 与 LRCLIB 歌词查询，不上报任何数据；LRCLIB 查询只带歌名、歌手与时长。

网易云走的是非官方接口。

## 启用同步后

同步是可选功能。启用后歌单与注释以明文推送到你自己的 git 仓库；登录态加密后推送，口令不上传。文件夹歌单、仅本机歌单、本地曲目注释与本地歌词绑定不会进入仓库。

`sync-key`、`sync-token` 与 `sync.toml` 都在 `~/.config/zero-beat/`，权限 0600。

## 封面与系统媒体

封面只为系统媒体面板下载并缓存（64 MiB 上限），不会上传到别处。
