# 下载与本地优先

## 在 TUI 里下载

在曲库用 `←` / `→` 切换操作焦点：歌单焦点下 `↑` / `↓` 选歌单，歌曲焦点下选歌曲。

- `W`：下载当前焦点里的选中项。歌单焦点下下载整个歌单；歌曲焦点下下载选中曲目，多选时批量下载。
- `w`：下载当前正在播放的歌，任意页面都可以（帮助/登录页除外）。
- 下载到 `~/Music/zero-beat`；底部显示进度，同时最多 2 个，其余排队。
- 已下载且文件有效的歌不会重复入队；中断后保留未完成文件，再下同一首会接着续传。
- 本地曲目（`[本]`）已经是本地文件，按 `w` / `W` 只会提示「不需要下载」，也不会在下载页留下 `source=local` 的记录。
- 下载失败会常驻在底部状态行（`✗ 曲名 下载失败 · 共 N 个 · F 查看`），进下载页后清理；已下过的歌再按 `W` 会直接跳过。

## 下载管理页

`F` 打开下载管理页：

| 键 | 作用 |
| --- | --- |
| `enter` | 播放（默认本地优先；关掉本地优先后走远程解析） |
| `W` | 重新下载选中项（文件缺失或 0 字节时强制补全） |
| `x` / `X` | 取消选中项的下载 / 取消全部 |
| `d` | 只移除记录（保留文件） |
| `D` | 删除本地文件 |
| `r` | 刷新 |
| `o` | 打开所在目录 |

缺失文件会标红。下载中的任务只在底部状态行展示，下载页只列已完成记录。

## 本地优先

默认开启「本地优先」：播放已下载歌曲时直接用本地文件；文件不存在或解码失败会在重试时回落远程。可在命令面板里切换（`N`）。

## 用 CLI 下载

```bash
zero download BV1GJ411x7h7 -o ~/Music/zero-beat/
zero download 2701880637 -q lossless
zero download BV1GJ411x7h7 2701880637 -j 2 -o ~/Music/zero-beat/
```

- 目标支持 BV 号 / B 站链接、网易云数字 ID / 网易云歌曲链接。
- 默认下载到 `~/Music/zero-beat`，文件名是「歌手 - 标题」；`-o` 指定目录或带扩展名的文件。
- 下载后直接封装，不重新转码，自动写好歌名、歌手、专辑信息。
- 常用参数：`-q auto|high|lossless`、`-p 分P`、`-j 1-8` 并发数、`-f` 覆盖已有文件。
- 可以一次传多个目标，`-j` 控制并发下载数。
- 中断或失败时保留 `*.part`，下次同目标运行会自动续传；续传不成功时从头重新下载。
- B 站的 artist 使用 UP 主信息；标题里通常还带歌手。

## 一些小限制

- 失败任务需要手动重下（按 `W`）。
- 只能下载当前账号有权限播放的曲目，VIP / 无版权会直接提示。
