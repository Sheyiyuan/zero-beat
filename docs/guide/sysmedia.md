# 系统媒体与封面（Linux）

Linux 下启动后，系统媒体面板、锁屏和媒体键就能控制播放了，也能看到当前曲目、时长、播放状态和封面。

## 能做什么

- 播放 / 暂停、上一首、下一首、停止、进度拖动、音量调节，都可以从系统媒体面板或媒体键操作。
- 随机与循环也能从面板设置，对应到四种播放模式。

| 面板上的操作 | 对应效果 |
| --- | --- |
| 循环 = 不循环 | 顺序（播完最后一首停止） |
| 循环 = 列表 | 列表循环 |
| 循环 = 单曲 | 单曲 |
| 随机 = 开 | 随机（洗牌队列） |
| 随机 = 关 | 恢复之前的模式 |

反过来也一样：在 TUI 里按 `p` 换模式，面板图标会立刻跟着变。顺序模式播到最后一首时，面板的「下一首」会置灰。

- KDE Plasma 5.27 / 6.x 的紧凑视图没有随机与循环按钮，需要**展开媒体控件**才能看到。
- 媒体键的具体按键取决于桌面环境；系统媒体只作用于本机，不上传任何数据。

## 封面

封面按需下载并缓存，上限 64 MiB，链接失效会自动重新下载。封面只在系统媒体面板里显示，终端界面本身不显示封面。

## 关闭与限制

- 想关掉就用 `ZERO_SYSMEDIA=0 zero` 启动。
- 系统媒体集成目前只在 Linux 提供。
- 播放器名称被占用时会明确提示，不会注册成第二个播放器。

## 单实例

同一数据目录只允许一个终端界面实例；重复启动会提示已有实例在运行。`zero download` / `zero sync` 等命令行操作不受影响。

设计与取舍见 [ADR 0017](../adr/0017-system-media.md)。
