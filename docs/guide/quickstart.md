# 快速上手

## 启动

直接运行 `zero` 进入终端界面。首次启动会落到曲库页，数据目录在 `~/.config/zero-beat/`，数据库是 `zero-beat.db`（SQLite）。

不想联网、只想看界面长什么样：

```bash
zero demo            # 打印一帧示例界面
zero demo lyrics     # 指定视图：library/search/queue/lyrics/help/login/clip/picker/downloads/menu/about/selection/sync/conflicts
```

## 登录

按 `L` 打开登录管理，B 站与网易云各自扫码登录，登录页同时显示两边账户状态。

- `↑` / `↓` 或 `s` 切换登录源；`ctrl+w` 退出登录（旧键 `W` / `X` 仍兼容）。
- 二维码按源懒加载并缓存 150 秒；`o` 用系统图片查看器打开 PNG 扫码（旧键 `v` 仍兼容）。
- 二维码用半块字符绘制，普通 24 行终端可完整显示；终端过矮时同样按 `o` 保存图片扫码。
- 也可以只用 CLI 登录单个平台：`zero login bilibili` / `zero login netease`。

登录 cookie 原样存在本地数据库里，当前未加密，详见[数据与隐私](privacy.md)。

## 界面与视图轮转

曲库是主页面：左栏歌单，右栏曲目，底部常驻歌词与播放条，左上角提示 `Tab` 切换页面。曲目前的 `[B]` / `[云]` 是来源标记。

- `Tab` / `Shift+Tab` 正向 / 反向轮转全部视图：曲库 → 本地搜索 → 音源搜索 → 队列 → 歌词 → 帮助 → 登录 → 导入歌单 → 下载 → 同步。
- `1`–`9` 直接跳前九个页面（不含同步页，同步页用 `Tab` 或 `ctrl+s`）。
- `b` / `esc` 返回曲库或取消输入；曲库有批量选择时 `esc` 先取消选择。
- `H` 打开/关闭快捷键弹窗，`?` 之外的帮助页可用滚轮或 `↑` / `↓` / `PgUp` / `PgDn` / `g` / `G` 滚动。

完整键位见[按键速查](../reference/keys.md)。

## 第一次播放

1. 登录后按 `f` 浏览并导入 B 站收藏夹 / 网易云歌单（按需导入，`s` 切换音源）。
2. 在曲库用 `←` / `→`（或 `h` / `l`）切换操作焦点：歌单焦点下 `↑` / `↓` 选歌单，歌曲焦点下选歌曲。
3. `enter` 或 `n` 播放焦点项；歌单焦点下把整个歌单载入队列并从第一首播放。
4. `space` 暂停 / 继续，`[` / `]` 上一首 / 下一首，`c` 打开队列。

曲库里蓝色底是当前焦点的选中项，灰色底是正在播放歌曲所属的歌单或当前歌曲；歌单左侧的 `▶` 表示正在播放的来源歌单。

## 断点恢复

退出时保存队列、当前曲目与进度，下次启动按 `space` 从断点继续。

## 找不到键？

- 任意视图按 `H` 看当前生效的键位弹窗（会显示自定义后的实际键）。
- 底部常驻提示当前页面可做的操作。
- 想改键位见[自定义快捷键](../reference/keymap.md)。
