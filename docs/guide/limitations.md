# 已知限制

这里整理了一些边界情况，提前知道可以少踩坑。

## 音源与版权

- 网易云走的是非官方接口，遇到风控或接口调整时，搜索和播放可能暂时失败，错误会显示在底部通知里。
- 网易云灰掉的歌、VIP 曲目、试听片段会明确提示。
- B 站收藏夹一次最多导入 300 首；B 站收藏夹和网易云歌单都需要按 `f` 手动导入。
- 云端歌单目前可以把歌加进去，删除、改名这类写操作还在路上；写网易云时通常只能写自己创建的歌单。

## 播放

- 歌词优先用平台自己的（B 站字幕 / 网易云 LRC），没有时用 LRCLIB；LRCLIB 靠歌名和时长匹配，冷门版本可能对错，可以用 `<` `>` 调偏移。
- 切歌前会提前备好下一首，间隙已经尽量压短；拖动进度会稍等约半秒到一秒。
- 播放模式是列表循环 / 单曲 / 随机 / 顺序四选一，不能叠加「随机 + 单曲循环」这样的组合。
- 自动响度均衡依赖 ffmpeg 的 `loudnorm` 滤镜；精简构建缺少该滤镜时开关不可用，但不影响普通播放。
- 自动响度均衡是单遍动态归一，不是逐曲静态分析，开启后仍可能听出轻微响度变化。

## 下载

- 下载失败后需要手动重下（按 `W`）。
- 本地优先播放时直接播已下载的文件，不会因为选择了更高音质就重新下载。
- 只有当前账号有权限播放的曲目才能下载，VIP / 无版权会直接提示。

## 歌单

- 混合歌单不套娃；要删除某个引用源之前，先在混合歌单里把它移除。
- 解锁同步歌单不可逆。
- 退出登录或登录过期后，远端歌单会冻结而不是删除；缓存曲目和混合歌单引用保留，重新登录自动恢复。

## 本地音乐库

- 文件夹歌单只扫描当前层，不递归、自动发现子目录，也不做文件监听；磁盘变化要等打开歌单（超过 60 秒）或按 `r` 重扫。
- 本地曲目身份来自音频标签，标题/艺术家/专辑/碟号/轨号完全相同的不同录音会被合并；暂无「拆分曲目」。
- 纯文本歌词、没有时间轴的歌词不能被使用；RAW LRC 文本粘贴绑定暂不支持。
- B 站字幕暂不作为歌词来源（需要先解析 CID）；纯文本 / 网页链接粘贴绑定会直接提示。
- CUE / APE 单文件多轨拆分、本地封面与完整的 MPRIS 元数据不在本期；本地封面暂不显示。
- `zero play <本地路径>` 暂不直接播放，请走文件夹歌单。

## 同步

- 同步按间隔进行，同一份歌单在两端都改过时需要手动选择。
- 歌单同步以明文托管，私有仓库只提供访问控制；git 历史不可撤销，换口令也不等于撤销旧密文。
- 同步需要系统安装 `git`；同一数据目录只允许一个终端界面实例。
- 同步登录态可能触发平台风控，失效时会回落到扫码登录。

## 平台

- 封面只在系统媒体面板里显示，终端界面不显示封面；封面缓存上限 64 MiB。
- 系统媒体集成目前只在 Linux；macOS 与 Windows 暂无系统媒体面板和媒体键，也没有桌面通知。可以用 `ZERO_SYSMEDIA=0` 关闭。
- Windows 提供了 zip 包，需要自己准备好 ffmpeg 和终端环境。

## 终端

登录页二维码用半块字符展示，普通 24 行终端可完整显示；终端过矮时按 `o` 用系统图片查看器打开 PNG 扫码。
