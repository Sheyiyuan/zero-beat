# 用户／歌手主页与播客电台接入验证

日期：2026-11-17。验证对象为当前工作区的 core 与 TUI 联调构建，输出 `bin/zero`，版本标签仍为 0.8.0。未替换用户全局安装的 `zero`。

## 接入内容

- core 新增可选 `source.Browser` 能力：主页引用、可进入的页面／可播放条目、分页结果、歌曲关联主页；GUI 可复用，不依赖 TUI。
- 网易云：多歌手主页与分页作品、用户资料／公开歌单／用户节目、热门电台／电台资料／节目列表、主播主页。
- B 站：视频关联 UP 主、WBI 用户资料和分页投稿接口。
- 评论新增作者主页引用；TUI 评论区 `O` 打开屏幕顶部评论的作者主页。
- 网易云节目使用 `program:<节目ID>` 作为持久身份；播放时读取节目详情，使用 `mainSong.id` 请求标准音频接口，结果仍保持节目 ID。节目评论走 `A_DJ_1_` 资源，不混用歌曲评论。禁止把节目写入云端歌曲歌单，本地／混合歌单和播放队列可使用节目。
- TUI：歌曲菜单主页入口、命令面板主页链接／我的主页／热门电台入口、异步加载、分页、返回、重试、取消与迟到响应隔离，支持播放／排队／下一首／加入歌单／评论。

## 平台限制与使用入口

B 站主页接口在当前环境触发风控，不能把它记为真实主页内容验证成功。页面显示错误并支持 `r` 重试；不会自动改变登录态。网易云的付费、会员、隐私和版权限制继续由平台决定。

运行 `./bin/zero`，歌曲右键菜单选择「歌手 / 用户主页」；按 `N` 搜索「网易云播客」或「打开主页」。主页面板内 `enter` 打开／播放，`[`／`]` 翻页，`backspace` 返回，`esc` 关闭。离线示例：`./bin/zero demo profile`、`./bin/zero demo radio`。

## 当前播放作者快捷键验证

`profiles` 默认小写 `u`，固定使用按键时的当前播放曲目，与列表焦点无关；曲库、搜索、队列、歌词、下载、评论和推荐／主页浏览面板均遵循同一规则。多位作者去重后列出，方向键选择并回车进入；只有一位时自动请求主页，不保留多余的单项选择层。播客的所属电台不计为作者，只列主播。无当前曲目或无可用作者时给出明确提示。

评论作者主页使用独立可配置动作 `comment_author`，默认大写 `O`。选中曲目的关联主页仍可通过歌曲菜单或 `N` →「选中歌曲的歌手 / 用户主页」进入。
