# v0.6.1：登录态冻结与音量均衡

- 日期：2026-11-04
- 状态：已发布
- 上一版：v0.6.0

## 新功能

### 登录态过期与歌单冻结

- 后台每 15 分钟校验一次登录态；TUI 启动时也会校验。
- 网易云 `MUSIC_U` 还在、但账号接口已经返回空账号或 `301/302/401` 时，判定为登录过期并自动退出。
- 打开歌单、刷新远端或导入收藏夹时如果拿到过期错误，会立即触发同一套账号校验，不必等下一轮定时检查。
- 退出登录或登录过期后，该音源的远端歌单改为**冻结**而不是删除：
  - 保留歌单、已缓存曲目与隐藏项；
  - 保留混合歌单对它的引用，打开混合歌单仍能看到冻结前的缓存曲目；
  - 停止远端刷新；重新登录后自动解冻。
- 冻结歌单在侧栏显示 `[冻]`，标题显示「已冻结」，右键菜单的同步刷新置灰；空歌单会提示重新登录后恢复。
- 本地歌单、队列和播放进度不受影响。

### 单曲音量补偿

- `,` / `.`：全局音量补偿 ∓1 dB，沿用旧行为。
- `;` / `'`：当前曲目的额外补偿 ∓1 dB，叠加在全局补偿之上，范围 ±12 dB。
- 实际增益 = 全局补偿 + 单曲补偿，最终夹在 -20 ~ +12 dB，再经过 `tanh` 软限幅。
- 单曲补偿按歌曲保存，并写入 `annotations/<song>.json` 的 `comp_db` 字段，随跨设备同步。
- 状态栏同时显示全局补偿与单曲补偿，例如「补偿 +2 dB · 单曲 +1 dB」。

### 自动响度均衡

- `N` 命令面板新增「自动响度均衡」开关，使用 ffmpeg 的 `loudnorm` 单遍滤镜，
  目标为 **-16 LUFS / -1.5 dBTP**。
- 开启或关闭时，如果当前正在播放/暂停，会从当前位置重新起播当前曲目；
  其他情况下一首生效。
- 开关存在 `settings.auto_gain`，属于设备偏好，不跨设备同步。
- 启动时检查 ffmpeg 是否提供 `loudnorm`；精简构建缺少滤镜时命令面板显示「不可用」，
  普通播放不受影响。

## 修复

- 网易云登录过期后界面会一直显示「已登录」的问题。
- 退出登录时直接删除远端歌单镜像，导致混合歌单引用一起丢失的问题。
- 歌单被冻结后仍尝试请求远端、反复报错的问题。

## 升级注意

- `playlists` 表新增 `frozen` 字段，`store.Open` 会自动迁移，旧数据默认 `0`，无需手工操作。
- 新增设置项：`auto_gain`、`song_comp:<songID>`。旧版本不会读取这些键，升级时不需要清理。
- 同步注释新增可选字段 `comp_db`。建议多台设备一起升级后再同步；旧版本遇到该字段会跳过
  对应注释，不会影响歌单与队列。
- 单曲音量补偿会随注释同步；全局补偿、自动响度均衡按设备保存。
- 自动响度均衡依赖 ffmpeg 的 `loudnorm` 滤镜；`ffmpeg -h filter=loudnorm` 有输出即可用。
- 退出登录不再删除远端镜像，因此「清空已导入的远端歌单」只能通过
  `zero clean-playlists` 显式执行。

## 升级前验证

```bash
make check
go test -race ./...
```

手工检查：

1. 用过期账号启动：确认自动退出、远端歌单显示 `[冻]`，混合歌单仍能打开并显示缓存曲目。
2. 重新登录同一音源：确认歌单解冻，按 `r` 能重新拉取远端。
3. 播放一首歌，按 `;` / `'` 调整单曲补偿，状态栏数值变化；重启后仍在。
4. `N` → 自动响度均衡：确认当前曲目重新起播，状态栏出现「自动均衡」；关闭后恢复。
5. 两台设备：确认单曲补偿随注释同步，全局补偿与自动响度均衡保持各自的设备值。
