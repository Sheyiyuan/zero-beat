# 0018 本地音乐库：本地源 + 文件夹歌单 + 下载映射

- 状态：已接受
- 日期：2026-11-10
- 关联：ADR-0004（Track 与身份）、ADR-0010（多源）、ADR-0011（混合歌单）、ADR-0016（git 同步）
- 设计：[feature-local-library-and-lyrics.md](../feature-local-library-and-lyrics.md)

## 背景

播放器已经能播已下载的文件，但不能把一个本机目录当曲库：没有曲目行、没有歌词、
没有歌单，也没法把本地文件混进平台歌单。需求是「手动加一个文件夹，它就是一个
只读歌单」，同时不破坏已有的同步、队列、注释与混合歌单。

本地文件有三类麻烦：

1. 身份不稳定：路径会改名/移动，标签可以改；
2. 设备相关：路径不能在别的设备复现，不能进同步仓库；
3. 与下载重复：同一文件可能既是「平台下载」又是「本地曲目」。

## 决策

### 本地曲目复用 `songs`，身份来自标签

不新建本地曲目表。`source=local`、`remote_id` 由音频标签生成：

```text
title 为空 → "file:" + quick_hash
否则      → "m:" + sha256(normalize(artist) \n normalize(title) \n normalize(album) \n disc \n track)[:32]
```

`id = local:<meta_key>:1`。身份刻意不含 duration：时长经常缺失或取整，包含它会把
同一文件的转码副本拆成两条。代价是标题/艺术家/专辑/碟号/轨号完全相同的不同录音会
被合并；扫描时给 warning，文档写明取舍。

查找顺序固定为「同歌单路径 → 内容指纹 → 下载映射 → 标签身份键 → 新建」，
因此改名/移动（指纹不变）与改标签（路径不变）都不换 ID。

### 文件夹歌单是 `kind=folder` 的只读歌单

一个目录对应一个歌单，扫描结果物化到 `playlist_items`，路径索引放在
`library_files`。不递归、不监听、隐藏文件/符号链接/0 字节文件跳过；目录不可用
时保留上次内容，只更新 `scan_status`。打开歌单超过 60 秒才重扫，`r` 立即重扫。

### 下载目录天然可用：按路径复用平台身份

扫描每个文件前先查 `downloads.path`（`filepath.Clean` 后比较，新增索引）：
命中就用原来的平台 `song_id`，不创建本地曲目；下载记录被删掉后，下次扫描退回
本地身份。这样同一文件不会出现两个身份，下载目录可以直接当文件夹歌单用。

### 本地源是独立的 `Source`，但没有账号能力

`internal/source/local` 只实现取流与本地歌词：`Caps()=0`。新增
`CapAccount`，B 站/网易云置位、local 不置位；登录页、二维码轮换与账号摘要
只遍历 `Registry.AccountIDs()`。这样 `[本]` 标记正常，登录页不会被污染。

### 同步边界：整歌单取舍，而不是按条目过滤

文件夹歌单、引用文件夹的混合歌单、显式「仅本机」歌单都标
`playlists.sync_excluded=1`。导出与导入删除**共用**同一个
`ListPlaylistSnapshots` 查询（`WHERE sync_excluded = 0`）：只做一侧过滤会在
下一轮导入把本机数据删掉。`BuildSnapshot` 遇到「同步歌单里混入本地曲目」或
「同步混合歌单引用文件夹」直接报错，不静默过滤。

本地曲目只能加入 `sync_excluded=1` 的歌单；已同步的混合歌单不允许追加文件夹
引用——要引用，就新建一个从创建时就是仅本机的混合歌单。

## 理由

- 复用 `songs`：队列、注释、下载、混合歌单全按 `song_id` 引用，单独建表要改所有读路径。
- 身份来自标签而不是路径：用户重命名/移动文件是常态，身份跟着路径走会丢掉注释与歌词绑定。
- 不递归、不监听：层级、空目录、重名、移动目录的语义复杂；v1 先把「手动单层」做对。
- 双向过滤的同步契约：导入是整版覆盖，按条目过滤必然删数据。

## 后果

- 已知取舍：相同标签的不同录音会合并；需要后续「拆分曲目」。
- 文件夹歌单内容随磁盘变化，不能手动排序/加歌；换目录会整体重扫。
- 删除文件夹歌单保留歌曲行与注释，孤儿清理不在本期。
- `meta.v=2` 切断旧客户端（见 ADR-0020）。

## 替代方案

| 方案 | 不采用的原因 |
| --- | --- |
| 本地曲目单独建表 | 所有按 `song_id` 引用的路径都要改，收益只有语义洁癖 |
| 递归扫描 / 自动发现 | 层级、重名、移动目录语义复杂，v1 不值得 |
| 本地库参与同步 | 路径设备相关，无法复现，还会泄漏路径 |
| 导出时按条目过滤本地曲目 | 导入整版覆盖，过滤会在本机删数据 |
| 把 local 做成完整 Source | 登录页、二维码、远端歌单会被污染 |
