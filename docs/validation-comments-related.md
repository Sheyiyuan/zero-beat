# 评论区与相关推荐接入验证

验证日期：2026-11-17。构建产物为根目录 `bin/zero`（本地版本标识 0.8.0）。

## 实现范围

- core 新增 `CommentReader`、`RelatedRecommender` 两个可选接口及能力位，保留原有 `Source` 接口。B 站支持视频评论和相关推荐，网易云支持歌曲评论和相似歌曲。
- TUI 在歌曲右键菜单和歌词菜单中提供入口；`i` / `I` 打开评论/推荐，支持键位配置。面板内 `Tab` 切换，`esc` 关闭。
- 评论保留作者、正文、时间、点赞数和可取得的回复数；正文自动换行，支持滚动、分页和失败重试。推荐可以播放、加入队列、下一首播放或加入歌单。
- 请求异步执行，关闭时取消；歌曲 ID 和全局请求序号共同过滤过期响应。接口失败只显示在面板中。
- 本轮提供只读评论，不含发表评论、点赞、回复和展开楼中楼。B 站未登录时返回少量预览，显示登录提示并停止无效分页。

## 自动化验证

- `make check build`：两模块完整测试、vet、格式、文档链接和构建通过。
- core 和 TUI 的 `go test -race ./...`：通过。
- `scripts/check-core-deps.py`：Linux、macOS、Windows、Android 的 core 依赖边界和构建通过。
- 新增测试覆盖接口参数与解析、空结果、业务错误、时间单位、能力位、菜单和键盘入口、请求取消、旧响应隔离、翻页重试、推荐入队/播放命令、长评论及 100×30、60×18、40×12 帧尺寸。

## 构建后实际交互

在独立 PTY 中启动 `bin/zero`，使用临时 `XDG_CONFIG_HOME`、临时 SQLite 数据库及本地控制通道。未读取真实账号或改动用户歌单。

| 路径 | 实测结果 |
| --- | --- |
| B 站右键歌曲 → 评论 | 公开视频 `BV17x411w7KC` 返回 3 条未登录预览，正文正常展示，并提示登录后查看完整评论 |
| B 站评论 → Tab 推荐 | 返回 40 条，能滚动到最后一条并加入队列，当前播放状态保持不变 |
| 网易云歌曲评论 | `1431292823` 返回每页 20 条，完成第 1 页 → 第 2 页 → 第 1 页 |
| 网易云相似歌曲 | 返回 5 条，能打开加入歌单选择器 |
| 窄终端 | 运行时缩放为 40×12，评论能滚动到底，面板保持在帧内 |
| 异步关闭/重开 | 发起请求后立即关闭并打开另一面板，旧请求未重新打开或覆盖当前内容 |
| 既有同步回归 | CLI / go-git 两种后端，以及构建后 TUI 登录态同步开关，均通过原有临时仓库回归 |

真实接口测试验证了浏览、分页和推荐入队/选择歌单；推荐播放的队列定位与命令派发由 TUI 自动测试验证。期间 B 站视频信息接口出现过一次超时，重试成功。返回条数和可访问范围取决于平台，不作为固定产品保证。
