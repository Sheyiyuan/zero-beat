# v0.6.0：跨设备同步与 Linux 系统媒体面板

- 日期：2026-11-03
- 状态：已发布
- 上一版：v0.5.1

## 新功能

### 跨设备同步（可选）

- 本地/混合歌单、`keymap.toml`、单曲歌词偏移/片段与登录态同步到任意 git 仓库
  （GitHub 私有仓库、Gitea、自建裸仓库均可），一实体一文件，`merge=binary`。
- 登录态使用 Argon2id（64 MiB / 3 轮）+ XChaCha20-Poly1305 按音源加密；口令不上云，
  新设备输入一次即可。歌单与注释是明文 JSON，首次初始化必须确认。
- 冲突按实体整版选择：保留本地 / 保留远程 / 保留两者（歌单）；落选版本归档在
  `~/.config/zero-beat/sync/archive/`，解决时保留 merge commit，不 force push。
- 自动同步默认开启：启动拉取，变更 debounce 30 秒推送，网络失败按
  5s → 30s → 2m → 10m 退避；冲突时冻结。
- 同步页（`ctrl+s`）：状态、仓库/分支、连接方式、密钥、自动同步、冲突入口与归档目录；
  右下角同步状态可点击。另有独立冲突页。
- 连接方式由仓库地址派生，可一键切换 SSH / HTTPS；`sync-key` 按归一化仓库身份
  （host/path）识别，切换不会让本机密钥或登录态失效。
- CLI：`zero sync init/status/pull/push/conflicts/resolve/key rotate/archive`。

### Linux 系统媒体面板

- 通过会话 D-Bus 注册 MPRIS（`org.mpris.MediaPlayer2.zero`），系统媒体面板、锁屏与
  媒体键可控制播放/暂停、上下首、停止、进度与音量，并显示曲目、时长、状态与封面。
- 播放顺序也能从面板控制：`Shuffle` / `LoopStatus` 改为可写属性，映射到四种播放模式，
  模式变化会立即回发 `PropertiesChanged`，TUI 与面板显示始终一致；KDE 需展开媒体控件
  才有随机/循环按钮。`playerctl shuffle on`、`playerctl loop none` 等按目标值写入的
  客户端同样可用。
- 封面按需从平台 CDN 下载并缓存到 `~/.config/zero-beat/cache/covers`（64 MiB 上限），
  只服务系统面板；终端界面不渲染封面。
- `ZERO_SYSMEDIA=0` 可关闭；macOS/Windows 为空实现。
- MPRIS 名称被占用时明确报错，不再注册成第二个播放器；测试可用 `ZERO_MPRIS_NAME` 隔离。

### 单实例

- 同一数据目录只允许一个 TUI：启动时拿 `instance.lock`（flock / 独占文件，记录 PID），
  重复启动直接提示旧实例 PID；进程退出或崩溃后内核自动释放。
- CLI 子命令（`play` / `download` / `sync` 等）不占这把锁，仍可并行运行。

## 改进

- 同步页输入体验：在地址/分支/口令/令牌行直接打字即进入编辑，支持终端粘贴；
  口令至少 12 字符、输入不回显，长度不足时保留编辑态并提示；小键盘回车可确认。
- 口令/令牌粘贴保留内部空格，不再被普通文本框的空白折叠改写。
- 初始化前缺少明文确认或口令时，光标会跳到对应行并显示原因。
- 帮助页新增「同步」章节；README 补充同步页/冲突页按键、系统媒体与封面、发布清单。

## 升级注意

- 同步是可选功能，不开启时行为与 v0.5.1 一致；不会主动初始化仓库。
- `keymap.toml` 新增动作 `sync`（默认 `ctrl+s`），旧配置无需修改；`1–9` 仍只覆盖前九个页面。
- `sync-key` 的 `remote_hash` 改为归一化仓库身份。v0.6.0 开发期生成的旧密钥文件会被
  视为「属于另一个仓库」，重新输入一次口令即可。
- 播放模式增加第四种「顺序」（播完最后一首即停，对应 MPRIS `LoopStatus=None`），
  `p` 变成四态循环；原来的「顺序」按行为改名为「列表循环」，只是文案变化，
  已保存的模式值 0/1/2 含义不变、无需迁移。
- 同一数据目录只允许一个 TUI；CLI 子命令不占实例锁。Windows 仍只有交叉编译产物。
- 系统媒体集成只支持 Linux；桌面通知仍未做。

## 升级前验证

```bash
make check
go test -race ./...
```

手工：

1. 两台设备：A 创建仓库并推送，B 用口令加入；确认歌单、键位、登录态与注释都到达。
2. 同一歌单两端都改：确认进入冲突页，分别验证本地 / 远程 / 保留两者。
3. 切换 SSH/HTTPS、换口令、忘记密钥后重新加入。
4. Linux：系统媒体面板能显示曲目与封面，播放/暂停/上下首/进度/音量可用；
   删除封面缓存后播放下一首会重新下载。
